' Sequence diagram Website Yayasan BUM Pontianak (YABUN)
' Disusun dari routes/web.php dan controller di app/Http/Controllers

=== Login Admin
actor Admin
boundary Sistem
control Auth
entity Pengguna

Admin -> Sistem : Membuka halaman /admin/login
Sistem --> Admin : Menampilkan form login
Admin -> Sistem : Mengisi email dan kata sandi lalu klik Masuk
Sistem -> Auth : authenticate(email, kata_sandi)
Auth -> Auth : Cek batas percobaan login (maks. 5 per menit)
Auth -> Pengguna : Cari pengguna berdasarkan email
Pengguna --> Auth : Data pengguna
alt Kredensial valid dan peran admin/superadmin
  Auth -> Auth : Regenerasi session
  Auth --> Sistem : Login berhasil
  Sistem --> Admin : Redirect ke halaman dashboard
else Kredensial tidak valid
  Auth --> Sistem : Login gagal
  Sistem --> Admin : Menampilkan pesan email atau kata sandi salah
end

=== Logout Admin
actor Admin
boundary Sistem

Admin -> Sistem : Mengklik tombol Keluar
Sistem -> Auth : logout()
Auth -> Auth : Hapus dan regenerasi session
Auth --> Sistem : Session berakhir
Sistem --> Admin : Redirect ke halaman login

=== Tambah Donatur
actor Admin
boundary Sistem
control DonorController
entity Donatur
entity FinancialTransaction
control FinanceSummaryService

Admin -> Sistem : Mengklik tombol Tambah Donatur
Sistem --> Admin : Menampilkan form donatur dan donasi
Admin -> Sistem : Mengisi nama, nomor HP, tipe, kategori, total dan tanggal donasi
Admin -> Sistem : Mengklik tombol Simpan
Sistem -> DonorController : store(request)
DonorController -> DonorController : Validasi data (total donasi minimal Rp 1.000)
alt Data valid
  DonorController -> Donatur : create(nama, nomor HP, tipe)
  Donatur --> DonorController : Donatur tersimpan
  DonorController -> FinancialTransaction : create(pemasukan, kategori, jumlah)
  FinancialTransaction --> DonorController : Transaksi tersimpan
  DonorController -> FinanceSummaryService : clearCache()
  DonorController --> Sistem : Redirect ke daftar donatur
  Sistem --> Admin : Menampilkan pesan Data donatur dan donasi berhasil ditambahkan
else Data tidak valid
  DonorController --> Sistem : Kembali dengan pesan validasi
  Sistem --> Admin : Menampilkan pesan kesalahan pada form
end
